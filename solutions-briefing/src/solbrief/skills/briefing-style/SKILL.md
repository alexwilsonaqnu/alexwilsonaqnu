# Briefing style guide (draft — finalized in Milestone 5)

- Audience: working reporters on deadline. Plain, scannable, no hype, no adjectives doing the work of evidence.
- Every factual sentence cites a library card or problem record by id. No facts from model memory.
- Lead each problem with two lines: what happened and why it matters today (local data point if available).
- Label every item **Solution lead** or **Service guidance**; never mix them in one item.
- For each card: the response in one sentence, the evidence-grade badge, the key limitation to probe, and
  the **Provisional** label when the card has fewer than two independent sources.
- One expert to call and one critic/skeptic, each with an institutional contact path. If none is verified,
  point to SciLine's free expert-matching service for reporters.
- A suggested story angle the card actually supports. Prior coverage, if any, so reporters don't duplicate it.
- Length budget: 3–5 problems, 2–3 cards each.
